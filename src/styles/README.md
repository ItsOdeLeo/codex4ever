# 样式管理

页面只加载 `theme.css`，按顺序导入配色、基础排版、Reset 组件和视觉主题。目前启用参考 [Poolsuite](https://poolsuite.net/) 的浅色复古桌面主题。

| 文件 | 管理内容 |
| --- | --- |
| `theme.css` | 唯一入口，只启用一套配色与视觉主题 |
| `palettes/poolsuite.css` | 当前基础色与全部语义角色 |
| `palettes/poolsuite.source.json` | 原站公开样式、预览、颜色来源与角色 |
| `retro-desktop.css` | 当前窗口、按钮、高光、阴影、字体和线宽 |
| `base.css` | 基础间距、布局、响应式和时间轴日期定位 |
| `../components/reset-element.css` | 两次 Reset 曲线、标记与操作的共用规则 |
| `palettes/radix.css` + `color-block.css` | 保留的 Radix 浅色主题 |
| `palettes/moss-paper.css` + `paper.css` | 保留的旧纸张主题 |
| `palettes/collections.css` | 保留的图片取色方案 |
| `palettes/founder-os.css` + `liquid-glass.css` | 保留的 Founder OS 深色主题 |

## 当前风格与角色

从 Poolsuite 的公开主题变量参考浅粉桌面、奶油色窗口、薄荷绿按钮和浅黄提示。独立实现小圆角窗口、1px 深色边框、轻微硬阴影与按钮内侧高光，不复制原站脚本、图片、商标或字体，也不增加运行依赖和 CDN 请求。

| 角色 | 颜色与形状 |
| --- | --- |
| 页面背景 | 浅粉 `#F7D5D5` |
| 面板和图表 | 奶油 `#FAF1E8` |
| 主操作、额度填充 | 薄荷绿 `#AFE5DD` |
| 备用 reset | 浅黄 `#FAF5C6`，保留为虚线边、使用为实线边 |
| 首次预测 | 深玫瑰色 `#7B6B6B` 细实线，选中操作为浅粉底 |
| 第二次预测 | 深薄荷色 `#58736F` 细虚线，选中操作为薄荷绿底 |
| 文字、窗口边界、额度轮廓 | 深色，风险用红色边界和下划线辅助标记 |

所有实际色值只在配色文件中定义。普通文字、控件文字和预测小字在桌面与两级面板上的对比度由已有检查验证。字体角色统一在 `retro-desktop.css` 管理：界面文字使用系统字体；`--font-reading` 只用于长篇预测说明、原始帖文、提示和页脚；`--font-brand` 管理标题和域名印章，英文用 [VT323](https://github.com/google/fonts/tree/main/ofl/vt323)，中文名用 [Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font) 12px（中文标题固定 24px，即两倍像素）。两款字体只保留名字用到的字形，直接内嵌在 CSS 里，首屏即为像素字体，不发字体请求。公式保留支持数学符号的等宽字体。数字输入和滑块读数使用同一界面字体，按别名的125%尺寸校正调整字号。字体原文件和 SIL OFL 声明位于 `public/fonts/vt323/` 与 `public/fonts/fusion-pixel/`。

首次和第二次假设的未选标题、已选标题、取消文案和悬停提示统一定义在 `reset-element.js` 的状态表里，经同一个动作模板渲染。`reset-element.css` 管理共用尺寸与状态结构，主题文件只覆盖配色和窗口外观；页面与时间布局不另写按钮模板。

本地服务补充 `.ttf` 的 `font/ttf` 类型，让新主题的字体以正确 MIME 类型提供；主题本身不能决定服务端响应头，因此这是必要的最小接入。其余资源路由、响应行为和字体之外的调用方不变，无新增服务依赖。

概率分布不填充面积，两次共用 1.2px 细线，最可能时间引线为 1px。额度保持实际耗尽位置和耗尽后的直线；不使用滤镜、纸纹、模糊或装饰动画。顶部日期、每天等宽和图表宽度仍由原布局模块计算，小概率标注省略规则继续有效。

换主题只切换配色与视觉文件，不叠加多套主题，不修改算法、用量、备用选择、概率或时间坐标。首次和第二次预测仍共用 Reset 组件，通过角色变量和实虚线区分。旧主题完整保留，可从统一入口切回。

顶部中英切换按钮沿用复古按钮规则，不使用下拉菜单。首次／第二次最可能标记的标题与时间使用对应的曲线颜色，累计值保留深色；第二条曲线的条件短语单独着色。新增常显的预测说明窗口沿用奶油面板、细边框和现有配色，展示实际样本范围、公式及当前假设。两条曲线使用的颜色在奶油背景上均满足小字号4.5对比度。语言选择、取样数据及数学公式由独立呈现模块提供，样式层不计算或更改概率。

页面不再提供用量滑块：“稳如老狗”固定按当前日均用量规划，其他策略自行计算所需日均。
