规划你的 Codex 用量

Codex4ever 是 OpenAI Codex 的非官方用量规划器。它比较当前额度还能用多久、何时可能需要备用 reset，以及额外重置预测对用量安排的影响。

从当前额度开始

填写本周剩余额度、距离正常刷新的时间，以及备用 reset 的到期日期。规划器根据七天窗口中已消耗的额度和已经过去的时间估算日均消耗。你可以调整用量，比较预计在哪个时间耗尽。

比较使用策略

支持保持当前用量、不浪费额度（在下次补满前用完）、仅工作日使用和周末集中使用。时间轴展示剩余额度、实际预计耗尽点、停用空档和规划中的补充。预测额外重置能够覆盖用量时优先考虑该补充，保留有限的备用 reset 作为后路。

理解额外重置预测

公开历史 reset 公告用于估计间隔分布和常见发布钟点。当前活动内的历史，以及可获取的 Tibo 帖子和回复，也会影响预测。第一条曲线预测下次额外 reset；第二条以首次在标记时刻发生为条件。累计概率表示截至某个时间发生事件的可能性，不保证个人账户一定刷新。

查看假设，再按实际情况重算

假设发布后，可以查看恢复额度的情景，以及此前各段的建议日均用量。模型中每次模拟 reset 都会重新开始七天窗口。实际发生 reset 后，需要核对账户余额和刷新时间，再重新计算。模型仍处于实验阶段，概率尚未校准。

通过 MCP 使用同一套规划器

本地 MCP 服务向 Codex 等宿主提供公开 reset 证据和策略工具。宿主可以分析帖子，将结构化证据交给规划器；独立运行时也可以连接标准 LLM API。不连接模型也能使用核心计算。

账户由你控制

网页在浏览器内计算计划，获取公开证据时不会发送你填写的额度。本地 MCP 可在请求时读取本机已登录 Codex 的用量。两个入口都不会自动兑换 reset 或消耗 credits。

常见问题

Codex4ever 是 OpenAI 官方的吗？

不是。Codex4ever 是独立开发者制作的非官方规划器，以 MIT 协议开源，与 OpenAI 无隶属或背书关系。

网页会把我的额度发送到服务器吗？

不会。网页在浏览器内计算计划，只下载公开的 reset 证据，你填写的额度不会离开页面。

Codex4ever 会自动兑换备用 reset 或消耗 credits 吗？

不会。它只建议日均用量，并显示备用 reset 何时可能有用。是否兑换由你在 Codex 中决定。

额外 reset 是怎么预测的？

预测依据公开的历史 reset 公告、当前 reset 活动，以及 OpenAI Codex 团队 Tibo 的公开帖子。概率是实验性估计，不保证个人账户一定刷新。

怎样在 Codex 里使用 Codex4ever？

运行 codex plugin marketplace add ItsOdeLeo/codex4ever，再运行 codex plugin add codex4ever@codex4ever 安装插件。新开对话，让 Codex 根据当前额度规划用量即可。它读取本机已登录账户的额度，不需要另外的 API key。
