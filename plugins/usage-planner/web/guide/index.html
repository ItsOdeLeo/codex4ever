Plan your Codex usage

Usage Planner (formerly Codex4ever) is an unofficial planner for your OpenAI Codex weekly quota. It shows how long your quota lasts at your current pace, when an extra reset is likely, and when a banked reset is worth using.

Start with your current quota

Enter how much of this week's quota is left and how long until the normal refresh, plus the expiry dates of any banked resets. The planner works out your daily usage from what you have used so far and shows when you would run out.

Pick a strategy

Keep pace uses your current daily rate. Keep available slows down so you never run dry. Use it all spends everything before the next refill. Weekdays only and Weekends only put all the usage on those days. The timeline shows daily usage, remaining quota, refills and when you would run out.

Read the reset forecast

The forecast learns from every public reset announcement: how far apart resets are and what time they usually land. Posts by Tibo of the Codex team count too, and an announced reset is shown at its announced time. The first curve is the next extra reset; the second assumes the first happens at its marker. These are estimates, not promises.

Plan without resets too

Turn on Assume no reset to see every strategy planned as if no extra reset comes. Each refill, whether a banked reset, the normal refresh or a reset, starts a new seven-day cycle. After a real reset, update your quota and plan again.

Use it inside Codex

The Codex plugin reads your signed-in quota on your own computer and opens the same planner beside the chat. Other MCP clients can use the npm package usage-planner. The forecast works without any API key.

Your account stays yours

The website calculates everything in your browser and never sends your quota anywhere. Neither the website nor the plugin redeems a reset or spends credits for you.

Frequently asked questions

Is Usage Planner affiliated with OpenAI?

No. Usage Planner is an unofficial, MIT-licensed planner built by an independent developer. It is not affiliated with or endorsed by OpenAI.

Does the website send my quota to a server?

No. The website calculates your plan in your browser. It only downloads public reset evidence, and your quota inputs never leave the page.

Does Usage Planner redeem banked resets or spend credits?

No. It only recommends a daily usage rate and shows when a banked reset could help. You decide whether to redeem anything in Codex.

How are extra resets forecast?

The forecast uses public historical reset announcements, the current reset campaign and public posts by Tibo of the OpenAI Codex team. Its probabilities are experimental estimates, not guarantees that your account will refresh.

How do I use Usage Planner inside Codex?

Install the plugin with: codex plugin marketplace add ItsOdeLeo/usage-planner, then codex plugin add usage-planner@usage-planner. Start a new chat and ask Codex to plan your usage from your current quota. It reads your local, signed-in quota and needs no separate API key.
