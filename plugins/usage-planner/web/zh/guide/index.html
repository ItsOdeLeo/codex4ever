赛博牛马规划器
English · 中文

规划你的 Codex 用量

赛博牛马规划器（英文名 Usage Planner，原名 Codex4ever）是 OpenAI Codex 每周额度的非官方规划工具。它告诉你按现在的速度额度能撑多久、额外 reset 大概什么时候来，以及备用 reset 什么时候值得用。

从现在的额度开始

填上本周还剩多少额度、离正常刷新还有多久，有备用 reset 的话再填上到期日期。规划器会根据你已经用掉的额度算出每天的用量，并告诉你什么时候会用完。

选一种用法

稳如老狗：按现在的速度用。细水长流：必要时放慢，保证一直有额度。赛博牛马拉满：在下次补满前全部用完。周末躺平、周末卷起来：把额度集中在对应的日子。时间轴上能看到每天用多少、剩多少、什么时候补满、什么时候用完。

看懂 reset 预测

预测参考了所有公开的 reset 记录：两次 reset 一般隔多久、通常在几点发。Codex 团队 Tibo 发的帖子也会算进去；他已经宣布的 reset，会直接按宣布的时间显示。第一条曲线是下一次额外 reset，第二条假设第一次发生在标记的时间。这些都是估算，不是保证。

也看看没有 reset 的情况

打开「假设没有 reset」，所有用法都会按一次额外 reset 都不来重新规划。每次补满（备用 reset、正常刷新或额外 reset）都会重新开始 7 天周期。真的 reset 之后，更新额度再算一遍就行。

在 Codex 里直接用

装上 Codex 插件后，它会在你自己的电脑上读取已登录账户的额度，并在对话旁边打开同一个规划器。其他 MCP 客户端可以用 npm 包 usage-planner。预测不需要任何 API key。

账户始终在你手里

网页的所有计算都在浏览器里完成，不会把你的额度发到任何地方。网页和插件都不会替你兑换 reset，也不会消耗 credits。

常见问题

赛博牛马规划器是 OpenAI 官方的吗？

不是。赛博牛马规划器是独立开发者制作的非官方规划器，以 MIT 协议开源，与 OpenAI 无隶属或背书关系。

网页会把我的额度发送到服务器吗？

不会。网页在浏览器内计算计划，只下载公开的 reset 证据，你填写的额度不会离开页面。

赛博牛马规划器会自动兑换备用 reset 或消耗 credits 吗？

不会。它只建议日均用量，并显示备用 reset 何时可能有用。是否兑换由你在 Codex 中决定。

额外 reset 是怎么预测的？

预测依据公开的历史 reset 公告、当前 reset 活动，以及 OpenAI Codex 团队 Tibo 的公开帖子。概率是实验性估计，不保证个人账户一定刷新。

怎样在 Codex 里使用赛博牛马规划器？

运行 codex plugin marketplace add ItsOdeLeo/usage-planner，再运行 codex plugin add usage-planner@usage-planner 安装插件。新开对话，让 Codex 根据当前额度规划用量即可。它读取本机已登录账户的额度，不需要另外的 API key。
